# Upgrade Report — 2026-10-06

## Scope

This upgrade keeps the current research topic and the existing within-subject, counterbalanced two-round design. It does not introduce a second passage, new question set, live LLM transformation, or participant accounts.

## Changes implemented

### Public/admin separation

- Removed the public `Admin sign in` link from the landing page.
- Removed public researcher readiness codes from the unavailable-study state.
- Admin authentication is still available at `/admin/login` when the researcher enters that path directly.
- `/admin/` remains disallowed in `robots.ts` and admin login metadata remains `noindex, nofollow`.

### Pre-question review stage

The state machine is now:

```text
INFORMATION → CONSENT → DEMOGRAPHICS
→ READING_1 → REVIEW_1 → TEST_1
→ BREAK
→ READING_2 → REVIEW_2 → TEST_2
→ COMPLETED
```

The review screen is intentionally neutral. It confirms the reading round is complete and explains the five-question procedure. It does not re-display the passage or expose questions, answer options, answers, score, or V1/V2 labels.

A new server-side transition endpoint confirms the review step before the participant can access `/experiment/test`. Manually navigating to the test URL while still at `REVIEW_1`/`REVIEW_2` redirects back to `/experiment/review`.

### V2 presentation aligned more closely to the topic

V1 remains a continuous standard presentation.

V2 now combines:

- narrower readable line length;
- larger text;
- increased line height;
- consistent spacing;
- visual grouping into short sentence blocks.

The visual grouping is generated by partitioning the canonical `rawContent` string. No character is generated, removed, replaced, summarized, or reordered. Joining every V2 block reconstructs the exact original source string. Unit tests cover this invariant.

### Lexical integrity validation

The previous check compared `rawContent` with itself. Publication/readiness checks now validate the actual V2 partition output reconstructed from the presentation function against the canonical source.

### Test updates

- E2E flow now passes through `/experiment/review` before each question round.
- Added E2E coverage that direct navigation cannot skip the review stage.
- Added E2E coverage that the public landing page exposes no admin link.
- Added unit coverage that V2 block partitioning preserves the exact source text and whitespace.

## Research rationale

The review screen is a UI transition, not an additional content exposure. Keeping the passage off the review screen avoids increasing reading time or changing the presentation intervention after the measured reading stage.

V2 remains a presentation-only intervention. The application does not add generated headings or summaries because that would conflict with the requirement that V1 and V2 contain the same lexical content.
