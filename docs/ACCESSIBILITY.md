# Accessibility

General application UI follows WCAG 2.1 AA-oriented principles:

- semantic headings, forms, fieldsets and labels;
- visible keyboard focus;
- readable validation/error states;
- keyboard-accessible buttons/links;
- responsive layouts and text;
- reasonable touch target sizes;
- reduced-motion support;
- horizontal overflow protection for data tables;
- progress communicated in text as well as visually.

Experimental manipulation is scoped separately from general application accessibility. `reader-v1` and `reader-v2` are applied only to the experimental content region so global styling does not erase the V1/V2 manipulation.

V2 changes presentation only; it does not alter lexical content.
