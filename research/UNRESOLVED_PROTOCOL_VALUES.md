# Unresolved Protocol Values

The supplied master requirements explicitly prohibit inventing research protocol content. This project therefore starts **not ready** and expects the researcher to enter approved values in the Admin dashboard.

`NEEDS_PROTOCOL_VALUE` applies to the following items until approved values are supplied:

- Official Participant Information Sheet wording and version.
- Official Consent wording and version.
- Official Debrief wording and version.
- Data-rights wording shown after completion.
- Findings-information wording shown after completion.
- Official raw experimental reading content.
- Published question set: exactly 5 MCQs, 4 options each, exactly one correct answer per question.
- Minimum reading time in seconds.

The 120-second break is not unresolved because it is explicitly fixed by the supplied requirements.

The system blocks new participant sessions until `Experiment Readiness Check` returns `ready: true`.
